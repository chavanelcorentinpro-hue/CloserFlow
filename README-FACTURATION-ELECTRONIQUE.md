# Facturation électronique — CloserFlow 6.1

Le module **Plus → Facturation électronique** prépare les données nécessaires à la réforme française :

- identification B2B/B2C/B2G ;
- contrôle du SIRET émetteur et du SIREN client ;
- contrôle des adresses, TVA et échéances ;
- export XML UBL 2.1 structuré.

## Limite importante

L'export est un socle technique de préparation. Il ne constitue pas encore un envoi réglementaire. La version finale devra se connecter à une plateforme agréée pour la transmission, la réception, les statuts de cycle de vie et le e-reporting.
