# CloserFlow 18.0.0 — Sales Autopilot

V18 ajoute un moteur commercial local directement exploitable sans service payant externe :
- scoring automatique des clients/prospects à partir des devis, missions, interactions portail et rendez-vous ;
- classement chaud / tiède / froid ;
- pipeline et valeur commerciale détectée ;
- recommandations d'action ;
- génération automatique d'une file de relances ;
- actions appel, e-mail, message et tâche ;
- changement manuel d'étape commerciale avec persistance locale ;
- message direct vers la messagerie client V17 ;
- accès croisé vers la relation client 360°.

Les modules V17 et antérieurs restent présents.
