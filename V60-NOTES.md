# CloserFlow 60.0.0 — Document Editing & Traceability

- Devis : modification après création.
- Chaque modification de devis sauvegarde la version précédente.
- Historique visible depuis le document.
- Facture brouillon : modification complète des lignes/client/TVA/remise.
- Facture déjà émise : l'original n'est pas écrasé ; création d'une copie de correction liée à l'original.
- Motif de correction conservé.
- PDF/impression utilise toujours la version courante du document.
- Compatibilité des anciens devis/factures via normalisation revision=1.
- Protections V57/V58/V59 conservées.
