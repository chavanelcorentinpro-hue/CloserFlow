# CloserFlow v8.3.0

## Facturation électronique avancée

- contrôle de conformité renforcé avec score sur 100 ;
- détection des identifiants, dates, lignes, quantités, prix et taux incohérents ;
- export XML UBL enrichi avec ventilation de TVA ;
- export XML CII ;
- dossier de preuve JSON incluant conformité, montants et suivi de transmission ;
- filtres pour factures prêtes, à corriger ou déjà transmises ;
- journal CSV enrichi avec score, erreurs, avertissements et dernière mise à jour ;
- suivi manuel des statuts et identifiants de dépôt.

Les exports sont des préparations techniques locales. Une connexion à un prestataire reste nécessaire pour transmettre et recevoir des statuts automatiques.
