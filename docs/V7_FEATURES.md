# CloserFlow v7.0.0

Version cumulative basée sur la v6.2.0.

## Nouveaux modules
- Bibliothèque d’ouvrages : prix d’achat, prix de vente, marge, unité, catégorie et TVA.
- Trésorerie prévisionnelle : factures à encaisser, dépenses à payer et prévisions manuelles.
- Réserves chantier : anomalies mineures, majeures ou bloquantes, avec levée et réouverture.

Les données de ces modules sont conservées localement dans le navigateur afin de rester disponibles hors ligne.
