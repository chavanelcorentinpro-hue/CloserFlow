# CloserFlow 17.0 — Expérience client

V17 consolide la relation client au lieu d'ajouter un module isolé :
- cockpit entreprise « Relation client 360° » ;
- demandes de rendez-vous depuis le portail avec acceptation/refus côté entreprise ;
- fil d'activité client local ;
- conversation entreprise/client centralisée ;
- synthèse chantiers, factures, reste à encaisser et paiements soumis ;
- portail client existant conservé (suivi, photos, devis/signature, factures/paiements, messagerie) ;
- données V17 persistées localement et incluses dans les sauvegardes ;
- version application portée à 17.0.0.

La V17 reste compatible avec la chaîne Android/Capacitor existante. Les paiements externes et l'authentification publique réelle nécessitent toujours un backend/HTTPS configuré.
