# CloserFlow v12.1 — Contrôle opérationnel

Nouveau cockpit local de supervision :

- factures échues et reste à encaisser ;
- conflits de planning par collaborateur ;
- missions acceptées ou en cours sans responsable ;
- stock sous le seuil minimum ;
- devis envoyés depuis plus de sept jours ;
- missions prévues sous trois jours ;
- chronomètres actifs ;
- filtres par domaine et niveau d'urgence ;
- export CSV du plan d'action.

Toutes les analyses sont calculées localement à partir des données existantes.
