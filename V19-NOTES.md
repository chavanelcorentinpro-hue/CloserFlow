# CloserFlow 19.0.0 — Company Autopilot

## Nouveautés
- Nouveau cockpit **Company Autopilot**.
- Calcul d'un score de santé global de l'entreprise.
- Consolidation temps réel : créances, impayés, pipeline devis, chantiers actifs, chantiers terminés non facturés, dépenses non réglées, stock critique, rendez-vous et messages clients.
- Générateur de plan d'action priorisé avec score de priorité.
- File d'exécution persistante localement avec validation des actions réalisées.
- Raccourcis directs vers ventes, finance, planning, stock et intelligence dirigeant.
- Interface responsive mobile.
- Conservation de tous les modules V1 à V18.
